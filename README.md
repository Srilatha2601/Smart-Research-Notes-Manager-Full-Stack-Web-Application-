# Smart Research Notes Manager

## About the Project
Smart Research Notes Manager is a full-stack web application designed to help users create, organize, manage and access research notes efficiently.

## Features
- Create and manage research notes.
- Organize information efficiently.
- User-friendly interface.
- Store and retrieve research information.
